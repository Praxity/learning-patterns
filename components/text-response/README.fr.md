## Quand l’utiliser

- Les personnes apprenantes se rappellent, expliquent ou appliquent une idée dans leurs propres mots.
- Les personnes apprenantes rédigent une ébauche qu’elles comparent ensuite à une réponse modèle ou à une liste de vérification.

## Quand l’éviter

- Lorsque la réponse fait partie de quelques options connues, utilisez l’[Option de réponse et marque de résultat](../choice/README.md).
