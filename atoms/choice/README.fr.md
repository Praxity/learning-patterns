## Quand l’utiliser

- Les personnes apprenantes reconnaissent la bonne réponse parmi quelques options plausibles.
- Chaque mauvaise option reflète une erreur que les personnes apprenantes font vraiment.

## Quand l’éviter

- Lorsque les personnes apprenantes doivent se rappeler la réponse ou l’expliquer elles-mêmes, utilisez la [Réponse écrite avec étiquette](../text-response/README.md).
