## Quand l’utiliser

- Une courte réponse écrite peut révéler une croyance erronée, et les personnes apprenantes ont besoin d’une rétroaction sur leur raisonnement.

## Quand l’éviter

- Lorsque vous ne pouvez pas modifier et tester ce que le modèle vérifie pour les idées fausses de votre sujet, utilisez [Vérifiez votre réponse](../self-check/README.md).
- Lorsque les personnes apprenantes peuvent expliquer elles-mêmes les erreurs courantes, utilisez [Rédigez les mauvaises réponses](../write-distractors/README.md).
- Lorsque vous avez besoin d’une note, utilisez une évaluation. Cette interaction aide les personnes apprenantes à améliorer leur raisonnement.
