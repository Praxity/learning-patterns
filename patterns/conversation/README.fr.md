## Quand l’utiliser

- Les personnes apprenantes doivent s’exercer à une conversation difficile où chaque réplique change la réaction de l’autre personne.
- Les personnes apprenantes savent quoi dire, mais sous pression, elles se défendent, attaquent ou se retirent.

## Quand l’éviter

- Lorsque vous avez besoin d’une note pour les habiletés de conversation, utilisez un jeu de rôle évalué. Cette interaction donne une rétroaction sans note.
